
# tg-keys
A tool for extracting Telegram's API keys.

## Installation
### For Termux users (Termux)
```bash
echo "deb [trusted=yes] [https://raw.githubusercontent.com/error-404-h/tg-keys/main/debian](https://raw.githubusercontent.com/error-404-h/tg-keys/main/debian) ./" > $PREFIX/etc/apt/sources.list.d/tg-keys.list
apt update
apt install tg-keys -y
```
For users of other systems (Linux, Windows, Mac), you can download the version appropriate for your device from the Releases section https://github.com/error-404-h/tg-keys/releases/tag/v1.0.0
